# Привет, я Ксения! 👋

Разрабатываю веб-приложения, локальные инструменты для работы с данными и игры. В уроках по генеративному ИИ и вайб-кодингу показываю взрослым и подросткам, как собрать рабочий прототип и проверить его на практике.

## Проекты

- **[StudyQuest](https://github.com/KseniyaZaitseva1/studyquest)** — браузерная игра для подростков. За выполненные учебные задачи игрок получает очки, покупает снаряжение и развивает героя для боёв с монстрами. HTML, CSS, JavaScript.
- **[Каталог нейросетей](https://github.com/KseniyaZaitseva1/ai-neural-networks-library)** — подборка ИИ-инструментов и готовых промптов. В каталоге можно отфильтровать сервисы по категории и стоимости. React, Vite, Tailwind CSS.
- **RenovaPro** — лендинг ремонтной компании и система работы с клиентами (CRM). Заявки с сайта попадают в кабинет менеджера, где он ведёт задачи и историю работы с клиентом.
- **Инструмент для обезличивания таблиц** — настольное приложение для Excel, CSV и TSV. Оно заменяет выбранные значения перед обработкой таблицы и восстанавливает их по ключу, который хранится на компьютере.
- **Семейный веб-сервис** — общий календарь, список желаний и интерактивный фотоальбом. Данные хранятся локально в SQLite.
- **Dragon Pixel Quest** — пиксельная аркада на Unity. Игрок управляет драконом и защищает сокровища от волн противников.
