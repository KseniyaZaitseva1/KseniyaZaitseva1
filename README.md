# Привет, я Ксения!

Разрабатываю практические уроки по генеративному ИИ и вайб-кодингу для взрослых и подростков. С Codex создаю веб-приложения, инструменты для работы с данными и игровые прототипы. В учебных проектах показываю, как описать задачу, собрать первый рабочий вариант и проверить его на пользовательских сценариях.

## Открытые проекты

- **Дизайн учебных презентаций ZeroCoder.** Система для создания автономных HTML-презентаций. В репозитории есть шаблон, галерея слайдов и скилл Codex с правилами оформления. [Шаблон и галерея](https://github.com/KseniyaZaitseva1/zerocoder-presentation-design)
- **StudyQuest.** Браузерная игра для подростков. За выполненные учебные задания игрок получает очки, покупает снаряжение и развивает героя для боёв на арене. [Код StudyQuest](https://github.com/KseniyaZaitseva1/studyquest)
- **Каталог нейросетей.** Веб-приложение с фильтрами по категории и стоимости, а также готовыми промптами. Сделано на React, Vite и Tailwind CSS. [Код каталога](https://github.com/KseniyaZaitseva1/ai-neural-networks-library)

## Другие разработки

- **RenovaPro** — лендинг ремонтной компании и CRM для менеджеров. Заявка с сайта попадает в воронку, где менеджер ведёт задачи и историю общения с клиентом.
- **Инструмент для обезличивания таблиц** — настольное приложение для Excel, CSV и TSV. Заменяет выбранные значения перед обработкой таблицы и восстанавливает их по ключу, который хранится на компьютере.
- **Семейный веб-сервис** — общий календарь, список желаний и интерактивный фотоальбом с локальным хранением данных в SQLite.
- **Игровые прототипы** — пиксельная аркада *Dragon Pixel Quest* на Unity и платформер *«Тень опаздывает»* на Python и Pygame.

## Чему учу

В курсе **«ChatGPT и Codex»** студенты собирают лендинг по брифу клиента, превращают запись встречи в протокол и рабочие материалы, подключают GitHub к Codex через MCP (Model Context Protocol). К урокам я готовлю презентации, которые открываются без интернета, исходные файлы, промпты и критерии проверки.

Для подростков разрабатываю занятия по вайб-кодингу, где ученики уточняют пожелания заказчика, составляют техническое задание и учатся по нему проверять результат.
